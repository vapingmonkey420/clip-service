# Third-party files in this folder

**fonts/Poppins-Bold.ttf, fonts/Poppins-ExtraBold.ttf**
Poppins, copyright 2020 The Poppins Project Authors. SIL Open Font License 1.1; full text in `fonts/OFL.txt`. From https://github.com/google/fonts/tree/main/ofl/poppins.

**models/face_detection_yunet_2023mar.onnx**
YuNet face detector, copyright 2020 Shiqi Yu. MIT License; full text in `models/LICENSE-yunet.txt`. From https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet.

To use a different caption font, add its `.ttf` or `.otf` here (check its licence allows it) and name it in the client's `captions.font`.
